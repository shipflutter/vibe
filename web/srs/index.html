    1. Executive Summary

    FightTech SSH is a Flutter SSH client for saving server connections, opening interactive SSH terminals, browsing remote files over SFTP, discovering LAN SSH servers, pairing desktop and mobile clients, and sharing/importing connection profiles through JSON and QR payloads.

    The SRS scope is the existing presentation feature set under lib/presentation. The document consolidates EP01 through EP09 from the current resources/ folder into a single SRS package.

    4. User Stories & Acceptance Criteria

    EP01 — SSH Terminal

    Story Title Acceptance summary
    EP01.US001 Start interactive SSH terminal SSH quick-connect opens terminal, shows selected connection, connects via SshBloc, disables input until ready.
    EP01.US002 Multi-tab terminal sessions User can add, switch, and close tabs without breaking remaining sessions.
    EP01.US003 Send terminal input and special keys Input row sends commands; Tab/Ctrl/Esc/arrows are available and disabled when disconnected.
    EP01.US004 Resize terminal cleanly Output expands, input/special keys stay visible, no overflow on supported surface.
    EP01.US005 Copy and clear output Copy writes visible output to clipboard; clear resets current tab without disconnecting.
    EP01.US006 Switch between terminal and SFTP Terminal exposes SFTP navigation for the same connection.
    EP01.US007 Error state and retry Error state shows message and retry reconnect action.

    EP02 — SFTP File Browser

    Story Title Acceptance summary
    EP02.US001 Browse remote files Shows connection name, current path, files, and directories; folders open on tap.
    EP02.US002 Navigate with path bar Breadcrumb/root/up controls navigate remote paths.
    EP02.US003 View file metadata Rows show size, permissions, modified time, and hidden-file indicators when visible.
    EP02.US004 Upload and download files Transfer actions exist and progress is visible until completion.
    EP02.US005 Manage files and folders Create folder, rename, delete with confirmation, and refresh after success.
    EP02.US006 Empty and error states Empty and error states are distinct and retry reloads current path.
    EP02.US007 Transfer cancellation In-progress transfer has cancel action and leaves browser usable.

    EP03 — Connection Management

    Story Title Acceptance summary
    EP03.US001 View saved connections Home loads via ConnectionBloc, shows connection details, loading, and empty states.
    EP03.US002 Add a new connection New form includes name/host/port/user, defaults port to 22, validates and saves.
    EP03.US003 Configure authentication Password/private key modes persist selected auth data.
    EP03.US004 Edit an existing connection Edit opens prefilled and updates the existing id; import-only actions stay hidden.
    EP03.US005 Delete a connection Confirmation required; confirm deletes and refreshes Home.
    EP03.US006 Quick-connect to SSH or SFTP Saved connection exposes SSH and SFTP actions.
    EP03.US007 Export and import connection data Export/import use ft-ssh-connection payload and do not log secrets.

    EP04 — Local Network Scanner

    Story Title Acceptance summary
    EP04.US001 Scan local network from home Home exposes Scan Local Network; scanner opens and starts automatically.
    EP04.US002 Display discovered SSH servers Results show count, IP, port, online badge, and banner when available.
    EP04.US003 Prefill New Connection from scanned server Tap result opens New Connection with name/host/port prefilled.
    EP04.US004 Manual fallback Empty state offers manual host/port entry and prefilled New Connection.
    EP04.US005 Retry scan Empty/error/app bar scan-again actions retry scanning.

    EP05 — Desktop Server & Mobile Pairing

    Story Title Acceptance summary
    EP05.US001 Start desktop pairing server Desktop starts HTTP/WebSocket pairing server and shows running status.
    EP05.US002 Show pairing QR code QR encodes IP, port, and security token.
    EP05.US003 Mobile scan pairing QR Mobile scans or manually enters URL to configure pairing.
    EP05.US004 Display active sessions Desktop lists paired device name, platform, IP, and connected time.

    EP06 — Desktop SSH QR Profiles

    Story Title Acceptance summary
    EP06.US001 Auto-fill desktop connection information Form can initialize local IP and username.
    EP06.US002 Create SSH QR profile Host/port/user/auth data creates QR payload and dialog.
    EP06.US003 Save profiles locally Profiles persist and reload through local store.
    EP06.US004 Manage QR profile history History supports show QR, edit, delete.
    EP06.US005 Show QR safely in dialog layout Dialog remains bounded and readable.

    EP07 — Mobile SSH QR Import

    Story Title Acceptance summary
    EP07.US001 Scan Desktop SSH QR Camera scan or pasted payload is accepted.
    EP07.US002 Parse SSH connection payload Parser validates type/version/host/port/user/auth.
    EP07.US003 Open New Connection with scanned data Edit-before-save opens form prefilled from payload.
    EP07.US004 Save imported connection Save dispatches existing connection save flow.
    EP07.US005 Connect after QR import Terminal/SFTP actions connect using imported connection.
    EP07.US006 Protect users from unsafe QR credentials Password-bearing payloads are treated as trusted-local sensitive data.

    EP08 — Connection Export

    Story Title Acceptance summary
    EP08.US001 Export saved connection as JSON Saved connection menu exposes export and creates ft-ssh-connection JSON.
    EP08.US002 Save exported JSON to a file Export can be saved with sanitized filename.
    EP08.US003 Generate QR code for mobile import Export dialog can show QR with bounded layout.
    EP08.US004 Copy exported JSON Copy writes export JSON to clipboard and shows feedback.
    EP08.US005 Share exported JSON Share sheet receives valid export payload.
    EP08.US006 Warn about sensitive exported credentials UI warns when payload contains password/private key.

    EP09 — New Connection JSON Import

    Story Title Acceptance summary
    EP09.US001 Import connection JSON from New Connection Create mode shows import action and cancellation preserves form.
    EP09.US002 Validate imported connection JSON Rejects invalid JSON/type/version/host/user/port/auth.
    EP09.US003 Support EP08 export payload Maps password/private key auth into form fields.
    EP09.US004 Prefill and review before saving Form fields populate and remain editable.
    EP09.US005 Save imported connection through existing flow Uses ConnectionSaveRequested, validation, and snackbar behavior.
    EP09.US006 Preview import flow with e2e screenshots EP09 script/report/screenshots document visual flow.

    10. Non-Functional Requirements

    ID Category Requirement Target
    NFR-001 Security Password/private key/passphrase values must not be logged. No plaintext secret logs in app or tests.
    NFR-002 Security QR and JSON payloads containing credentials are trusted-local sensitive data. Warnings in export/import flows.
    NFR-003 Reliability Save/import/export must use existing bloc/usecase paths. No persistence bypass.
    NFR-004 Usability Primary screens must render on 390x844 screenshot surface. No overflow in screenshot/golden tests.
    NFR-005 Performance Network scan runs concurrently and keeps UI responsive. Scanning state visible while work runs.
    NFR-006 Portability E2E screenshot flows run through Flutter driver. Per-epic e2e/e2e-ep*.sh reports.
    NFR-007 Recoverability Error states expose retry or fallback when possible. SSH, SFTP, scanner, pairing, import flows have recovery actions.

    11. Business Rules

    ID Rule Related stories
    BR-001 Connection port must be an integer from 1 to 65535. EP03, EP07, EP09
    BR-002 Edit Connection must not show New Connection-only import actions. EP03.US004, EP09.US001
    BR-003 ft-ssh-connection JSON must use supported type/version. EP08, EP09
    BR-004 Network scan selection pre-fills name, host, and port only; credentials remain user-controlled. EP04.US003
    BR-005 Imported QR/JSON connection must be reviewed before save/connect. EP07, EP09
    BR-006 Password-bearing QR/export payloads are intended for trusted local transfer. EP06, EP07, EP08
    BR-007 Save imported connection must dispatch normal ConnectionSaveRequested. EP07.US004, EP09.US005

    13. Risks / Assumptions / Open Questions

    Risk Impact Mitigation
    Credential QR/JSON shared outside trusted context Server credential exposure Warnings, review before save/connect, no logging
    LAN scan blocked by OS/network No discovery results Manual fallback and retry
    Pairing port conflict Server cannot start Auto-select available port
    Platform screenshot differences Review churn Stable screenshot surface and per-epic reports
    Feature docs drift from implementation Incorrect SRS Generate SRS from resources/ and trace to tests

    Assumptions:

    • Flutter app remains the primary implementation.
    • Local connection persistence remains available through the existing repository.
    • SSH/SFTP repositories provide platform-specific network behavior behind domain abstractions.
    • QR/JSON profile transfer is a trusted-local workflow, not a public sharing system.

    Open questions:

    • Dedicated per-use-case files do not yet exist; this SRS consolidates use cases from epic docs.
    • Detailed ERD for data-layer persistence is outside current presentation scope.
    • SFTP operation capabilities depend on repository/platform support and may require deeper data-layer SRS later.
